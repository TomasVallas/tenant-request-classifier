# Oppimismuistiinpanot: React ja TypeScript

Tähän kootaan projektissa käytetyt React- ja TypeScript-käsitteet sitä mukaa, kun ne tulevat koodissa ensimmäistä kertaa vastaan. Tavoitteena on, että osaat selittää jokaisen osan työhaastattelussa omin sanoin.

## Käsitelista

Rasti lisätään, kun käsite on selitetty alla ja sitä on käytetty projektin koodissa.
